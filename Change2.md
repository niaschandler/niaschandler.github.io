# Change 2 — About Page Profile

**Status:** Planning  
**Branch:** `more-about-me`

## Summary

> Draft a small amount of additional About copy that gives visitors a fuller sense of the person behind the roles, without turning the page into a full biography or résumé.

The writing should be reviewed in chat first. Do not add it to `about.md` until the user approves the final wording.

## Why this change

- Help visitors learn a little about education, service, volunteer work, and interests beyond the listed assignments.
- Keep the public profile concise and intentional about what personal information it shares.

## Goals

- [ ] Prepare a few short first-person copy options for review.
- [ ] Select only a few user-supplied details; do not include every credential, award, duty, or interest by default.
- [ ] Balance professional and service background with a personal detail if the user wants one.
- [ ] Keep victim-advocacy references high-level; do not disclose case or client information.
- [ ] Treat location, unit size, and performance-venue details as optional; include them only if the user explicitly approves.
- [ ] Preserve supplied credential names, dates, titles, ranks, and awards accurately. Do not invent or embellish.
- [ ] Leave `about.md` unchanged until the user approves the final copy.
- [ ] If implementation is later approved, preserve the existing layout and color scheme.

## Candidate material supplied by the user

- Education and Supply Corps training, including degree, course, honors, and awards.

## Scope

### Include

- A concise, human-centered addition to the public About copy.

### Do not include

- A full résumé or every detail supplied for consideration.
- Case-specific, client-identifying, or operational information.
- Location, audience-size, or event details that the user has not approved for the final copy.
- Any About-page content changes before approval.

## Acceptance criteria

- [ ] The user approves the final wording before it is added to the site.
- [ ] Every statement reflects information supplied by the user.
- [ ] The About page remains unchanged until that approval.
- [ ] This planning file is excluded from the generated website.
